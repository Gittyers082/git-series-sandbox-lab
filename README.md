# git-series-sandbox-lab

Git Series 1: Core Foundation and Collaboration

## What this is

A small student-directory web app (`index.html` + `app.js`) that renders a card
per student, read from `profiles/*.json`.
Just open `index.html` in a browser after cloning.

## Quick reference

| Action | Command |
| --- | --- |
| Clone your fork | `git clone <fork-url>` |
| Add the original repo as upstream | `git remote add upstream <original-repo-url>` |
| Fetch upstream changes | `git fetch upstream` |
| Create a branch | `git checkout -b feat/my-task` |
| Rebase on upstream main | `git rebase upstream/main` |
| Push your branch | `git push origin feat/my-task` |

See the companion **Student Hands-On Challenge Guide** for the 5 workshop challenges.
